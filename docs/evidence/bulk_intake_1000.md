> (fixed random seed 42) on reserved `.example` domains that can never be real websites. The rows were uploaded
> with `source=synthetic` (shown as "Test data", can be hidden), and **no run was started: nothing was crawled
> and no AI was called.** This measures the upload / validation path only.

Date: 2026-11-18 (UTC). Machine: Windows 11, local PostgreSQL 18, API (`uvicorn`, one process) on the same
machine. REAL request through `POST /api/uploads` as `reviewer@demo.local`.

## Result: PASS

The response lists only the 100 non-accepted rows (accepted ones are counted, not repeated); all rows can be
paged with `GET /api/uploads/{id}/rows?result=...`.

## Limits

- One request on one machine; times will differ on other hardware. Each row is one `INSERT ... ON CONFLICT DO
  NOTHING` round trip - fine at 5,000 rows (the upload limit), a bulk `COPY` would be needed for far larger files.
- Concurrency of two uploads of the same company is covered by `tests/test_ingest.py` (two threads, one company).
