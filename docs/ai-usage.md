## Concrete examples: accepted, modified, rejected

1. **Text-extraction bug found by a test (modified).** The first `extract` implementation split text on source-code
   line breaks, so a paragraph wrapped over two HTML lines became two lines ("Cash bids\ndaily"), which would have
   broken quote matching. The test failed; the code was changed so only block elements start new lines.
2. **Stitched and invented quotes (AI output rejected by our own validation).** On real runs, Gemini and Groq joined
   separate fragments into one "quote" (with "..." or skipped words) and once rewrote a sentence that did not exist.
   Every one was caught by the verbatim-quote check and dropped. Prompt p2 then asked for one continuous span -
   validation still guards it.
3. **A schema limit that rejected whole answers (modified).** The first schema had a hard 300-character limit on
   quotes; one 370-character quote made Gemini's otherwise good answer fail three times (and the run fell back to
   Groq). Size limits moved into validation per quote, so one bad quote costs one quote, not the answer.
4. **Prompt p2 -> p3 and the evaluation caveat (modified, with a stated limitation).** The fixture evaluation showed
   "our elevator closed in 2015" answered as `not_found` instead of `possible`. p3 added one rule; the re-run scored
   54/54 - but on the SAME 9 synthetic sites, so the documents state it is fit to our own fixtures, not real-world
   accuracy. The real-world signal is the manual audit of the 15-company pilot.
5. **LangGraph dropped (AI suggestion rejected).** The original plan used LangGraph with a Postgres checkpointer. It
   was replaced by plain staged functions because they are easier to explain in a live defence and still give a
   reproducible pipeline **[CANDIDATE TO CONFIRM: whose decision]**.
6. **The `.env.example` mistake during setup (process error caught).** While creating the local `.env`,
   `backend/.env.example` disappeared from the repository (apparently renamed instead of copied). The git-status check
   before the first commit noticed it was missing, and it was recreated from the placeholders. **[CANDIDATE TO CONFIRM: what happened on your side]**
7. **Real-site pilot results not accepted at face value.** The audit found two clear false negatives (Grow West
   agronomy, Star Oilco gas station) by reading the crawled pages, and a TLS failure mislabelled as
   `robots_disallowed`; these are reported as findings rather than hidden.
